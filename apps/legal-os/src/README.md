# Kuwait Legal AI — Implementation Guide

## Stack
- **Framework**: Next.js 14+ (App Router)
- **AI SDK**: Vercel AI SDK
- **LLM**: Fireworks AI (Llama 3.3 70B)
- **Embeddings**: Fireworks AI (nomic-embed-text-v1.5)
- **Database**: Neon Postgres + pgvector
- **Deployment**: Vercel
