# cars-4by4-builder

Loaded when working under this app. Repo-wide rules are in the root `AGENTS.md`.

## Env

- Local dev does not read `.env.local` at runtime: the workerd dev server reads
  `.dev.vars`, generated by `npm run dev-vars -w cars-4by4-builder` (shell env
  wins over this app's `.env.local`, which wins over the root `.env.local`).
- That generator **refuses to write** when `DATABASE_NEONDB_SMARTEKAI` points at
  production. Reach the rehearsal branch with
  `DATABASE_NEONDB_SMARTEKAI="$(npx neon connection-string cars-credits…)" npm run dev-vars`.
- Production env comes from `wrangler.jsonc` `vars` plus `wrangler secret put`.

## Deploy

`npm run deploy -w cars-4by4-builder` (`vite build && wrangler deploy`), config
in `wrangler.jsonc`: custom domain overlander.smartekai.com (cars.smartekai.com
is kept only to 301 GET/HEAD there), a `cars-render` Queue consumer, an hourly
cron. Workers **Free** plan: keep server CPU per request low.
